## Run locally

```bash
npm install
npm run dev
```

## Edit content

All resume content (skills, experience, projects) lives in `src/data.js`.

## Deploy

Every push to `main` builds and deploys to GitHub Pages automatically (`.github/workflows/deploy.yml`).
